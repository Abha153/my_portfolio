# Abha Portfolio — Updated Freelance Version

These files update the existing `my_portfolio` GitHub Pages site while retaining its Built by Curiosity look, UFO animation, dark/light theme, current projects, learning content, and writing section.

## Contents
- `index.html` — portfolio with a family-project portfolio reference, website pricing, workflow, FAQs, and an improved enquiry form. The Rishabh portfolio screenshot is embedded directly into this file, so it will still display if you forget to upload the separate JPG.
- `style.css` — current styles plus responsive styling for the new sections.
- `script.js` — UFO animation, theme toggle, package selection, and enquiry-form feedback.
- `rishabh_portfolio_preview.jpg` — standalone copy of the cropped portfolio screenshot, for reference or future updates.
- `curious_me.png` — existing portfolio illustration.
- `Abha_Tiwari_Resume_new.pdf` — resume asset from the current portfolio bundle.

## Deploy
1. Back up the current repository files.
2. Upload `index.html`, `style.css`, `script.js`, `curious_me.png`, and `Abha_Tiwari_Resume_new.pdf` to the root of the `my_portfolio` repository, keeping the names unchanged. The Rishabh screenshot is embedded in `index.html`; uploading `rishabh_portfolio_preview.jpg` is optional for this version.
3. Commit and push the changes.
4. Open the live site and test the theme toggle, package buttons, and enquiry form. FormSubmit may require inbox activation; a real submission has not been tested from this environment.

The portfolio reference is described as a family project rather than a paid client contract. Check the listed technologies against the stack actually used, and get permission to display the website before publishing.
